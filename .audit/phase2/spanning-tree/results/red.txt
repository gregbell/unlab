A port that never carried loses nothing when it is no longer made to stop, so a triangle that is built once blocks all the same. A port
that agrees to itself ends where one that waited does. A cut that the tree is not told of is found three hellos later, which the desktop's
test does not time. And a tree with no timer of its own is run whenever a frame crosses a cable, which the page's test sends every second.
The first of these is caught by the kernels' test of a cut, which reconnects the cable and so has a port stop carrying.
