# <https://unlab.run> Manual

Start with [Getting started](getting-started.md) to boot two machines in your
browser and send a ping from one to the other.

## Chapters

- [Introduction](introduction.md) explains what runs in your browser and how to
  read the Manual.
- [Getting started](getting-started.md) walks you through saving a file,
  installing software, and testing a connection before and after you cut a
  cable.
- [The desktop](the-desktop.md) shows how to use the rack, open terminals,
  follow cables, and arrange windows.
- [Machines](machines.md) covers Linux images, machine configuration, and power
  controls.
- [Storage and checkpoints](storage-and-checkpoints.md) explains how to add a
  disk and how to save and restore its contents.
- [Networks](networks.md) shows how to add switches, patch machine interfaces,
  change port settings, and inspect traffic.
- [Commands and the command bar](commands-and-the-command-bar.md) explains where
  to type a command, how to specify its targets, and how to read the result.
- [Connecting from your computer](connecting-from-your-computer.md) covers the
  command-line interface (CLI), SSH, file transfer, port forwarding, and
  internet access.
- [Automation and agents](automation-and-agents.md) describes how to run
  commands from scripts and choose which operations an AI agent can perform.
- [Troubleshooting](troubleshooting.md) lists symptoms and what to check.
- [Appendices](appendices.md) lists resource limits, CLI files, and environment
  variables.
